# Interactive Web Page

A frontend web project built with HTML, CSS and JavaScript.

## Technologies

- HTML
- CSS
- JavaScript

## How to view the webpage

Download or clone this repository.

Then open the project folder and double-click:

`index.html`

The webpage will open in your default web browser.

You do not need to install any dependencies or run a server for this project.

## Project structure

- `index.html` — main webpage.
- `styles.css` — page styling.
- `script.js` — JavaScript functionality.
- `apple.png` — image used by the webpage.
- `Screenshot of Application.png` — screenshot showing the finished application.

## What I practised

- Structuring a webpage with HTML.
- Styling a webpage with CSS.
- Adding interactivity with JavaScript.
- Linking HTML, CSS and JavaScript files together.
